# Security Policy

We take the security of the SV Tech website seriously. This policy applies to the
current production website and the `main` branch.

> **Language:** English | [Español](SECURITY_ES.md)

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues or pull requests.

Report them privately by creating a draft security advisory from the repository's
**Security** tab, or email [contacto@svtech.cl](mailto:contacto@svtech.cl). Include
the affected URL or component, steps to reproduce the issue, its potential impact,
and any relevant screenshots or proof of concept. Do not include real credentials
or other people's personal information in a report.

We aim to acknowledge reports within **48 hours** and will coordinate a fix and
disclosure timeline with the reporter.
